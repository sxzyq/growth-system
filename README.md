## 这个项目解决什么问题

1. **代替手写日记，记录更快**
   打字比手写快得多，想到什么立刻记下来，不用等翻记录本、找笔，今天的事今天就能写进「每日记录」。

2. **解决了记录本「不能及时更新」的问题**
   纸质日记经常因为没带在身边、忘记带笔而漏记，这款网页打开就能写，随时随地补上当天的心情和完成情况。

3. **不再怕日记丢失**
   手写日记怕丢、怕湿、怕撕坏；本应用的数据保存在浏览器本地存储中，只要不清除浏览器数据就不会丢。

4. **自动帮你复盘，不用自己翻日记**
   系统会自动统计**连续打卡天数**、生成**本周数据总结**、**评分趋势图**，省去手动翻页统计的麻烦。

5. **数据驱动的自我认知**
   通过评分、情绪颜色、标签等日常记录，自动生成「第三视角」综合洞察报告，像一位懂你的朋友帮你看见自己。

## 主要功能

共 7 个板块 + 3 种页面主题。

### 🏠 首页
- 按时段自动问候，展示「随机回顾」——随机翻出一条过去的记录
- 统计卡片：**记录天数**、**今日状态**
- **本月概览**迷你月历，一眼看到本月哪几天有记录
- **随手记**便利贴：快速记下容易忘的小事，回车添加，可清空已完成
- 成长伙伴吉祥物：点击它会和你互动

### 📝 每日记录
- **今日完成情况**：写今天完成了哪些事
- **百态**：记录美好/糟糕瞬间，支持**每天最多上传 5 张照片**（自动压缩保存，点击可放大）
- **今日标签**：场景 + 表情双分类，多选，用于后续情绪关联分析
- **情绪颜色**：选一种颜色代表今天的心情
- **今日评分**：1-5 星
- **今日反思** + **明日计划**
- 自动生成**今日摘要**
- 支持切换日期**补记往日**

### 📅 计划管理
- **每日待办**：按日期管理，显示完成进度条和鼓励语，一键清空已完成
- **每周任务**：按周管理，显示本周完成百分比进度条
- **阶段目标**：月目标 / 学期目标 / 年目标分类管理

### 📊 复盘统计
- **连续打卡天数**（今天没记录不会立刻断签，从昨天起算）
- **本周数据总结**：自动统计本周记录情况并生成总结文字
- **本周感悟**：每周写一段，自动按周归档
- **本周时间线**：按时间倒序回顾本周每天的内容

### 🖼️ 展示
- **日历视图**：整个月历，点击日期可标记 ⭐ 重要日或装饰色，也可查看某天详情
- **评分趋势图**：SVG 折线图，近 7 天 / 近 30 天切换

### 🔮 第三视角 · 个人洞察
- **综合洞察专属报告**：根据全部记录自动生成
- **本周洞察** / **本月洞察**：自动总结趋势
- **对比分析**：情绪颜色 vs 效率、评分 vs 反思深度、有无计划 vs 完成率
- **改善建议**：根据数据给出个性化建议

### 💬 独白
- **收集 · 摘录**：收藏在抖音、公众号等看到的好文案、好段落
- **随记 · 自己写**：写下自己此刻想说的话
- 点击「✨ 收录」存入列表，**按时间倒序展示**，支持**编辑**与**删除**

### 🎨 三种页面主题
| 模式 | 风格 |
| ---- | ---- |
| 正常 | 简约大气 |
| 绿色 | 蓬勃生机 |
| 夜晚 | 宁静平和 |

## 技术特点

- **零依赖零构建**：纯 HTML + CSS + 原生 JavaScript，动画库（GSAP）已本地化，**离线可用**
- **数据本地存储**：localStorage 存储，无需服务器、无需登录、不联网上传
- **数据自动迁移**：内置 v1 → v2 → v3 数据兼容迁移，旧数据不丢失
- **防覆盖保护**：保存时检测空数据覆盖风险，避免误清空已有记录
- **响应式动效**：纸角翻转、胶带剥离、便利贴边缘抬起、吉祥物互动等细节动效

## 安装方法

无需安装任何环境，两种方式任选：

### 方式一：直接访问在线版（推荐）
打开浏览器访问：

```
https://sxzyq.github.io/growth-system/
```

### 方式二：本地运行
1. 下载本项目所有文件（或 `git clone`）
2. 确保以下文件在**同一个文件夹**内：
   - `index.html`（入口）
   - `style.css`
   - `script.js` / `fx-effects.js` / `gsap-local.js` / `customease-local.js`
   - `mascot.png` 等吉祥物图片（`mascot*.png`）
3. 双击 `index.html`，用 Edge / Chrome 等浏览器打开即可使用

> 提示：不要直接在压缩包里打开，请先解压到本地文件夹再打开，否则图片资源可能加载失败。

## 使用方法

### 第 1 步：写第一条每日记录
点击左侧导航「📝 每日记录」→ 随便填一项（比如完成情况、选个情绪颜色、点星星评分）→ 内容会自动保存。

> 记录天数按「真实内容」判定：完成情况 / 百态 / 反思 / 明日计划 / 情绪颜色 / 评分 / 照片 / 标签，**任一有内容**即算记录了一天。

### 第 2 步：管理计划
「📅 计划管理」中添加每日待办、每周任务和阶段目标，完成后勾选即可看到进度变化。

### 第 3 步：看你的成长
- 「📊 复盘统计」：查看连续打卡天数和本周总结
- 「🖼️ 展示」：看日历和评分趋势图
- 「🔮 洞察」：查看自动生成的综合报告、对比分析和改善建议

### 第 4 步：切换主题
页面右上角可切换 **正常 / 绿色 / 夜晚** 三种模式。

## 输入输出示例

### 示例一：每日记录 → 首页统计

**输入**（在「每日记录」页填写）：
```
今日完成情况：背了 50 个四级单词，写完高数作业
情绪颜色：浅蓝
今日评分：⭐⭐⭐⭐
今日反思：专注的时候效率很高，明天继续保持
```

**输出**：
- 首页「记录天数」自动 +1
- 复盘统计「连续打卡天数」+1
- 展示页「评分趋势图」多一个数据点
- 洞察页生成对应的趋势与建议

### 示例二：独白 → 收录列表

**输入**（在「独白」页的「随记」框写）：
```
今天第一次独立跑通一个小功能，原来坚持真的会有回应。
```

**输出**：
```
「我的独白」列表顶部新增一条：
今天第一次独立跑通一个小功能，原来坚持真的会有回应。
  [编辑]  [删除]
（时间倒序排列，可随时编辑或删除）
```

### 示例三：随手记 → 便利贴

**输入**：在首页「随手记」输入框输入 `明天 8 点交实验报告` 并回车

**输出**：该条以便利贴形式出现在「随手记」列表中，完成可勾选，可一键「清空已完成」。

## 数据与隐私

- 所有数据（每日记录、计划、独白、照片、标记等）均保存在**当前浏览器的 localStorage** 中
- **不上传任何服务器**，离线可用
- 注意：数据与浏览器及文件路径绑定，**不同浏览器、不同设备之间数据不互通**；清除浏览器数据会清空记录，重要数据请自行留意
- 分享给他人时，压缩包为空白副本，不含本人记录数据
